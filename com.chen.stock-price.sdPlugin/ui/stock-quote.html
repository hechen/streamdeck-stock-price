Shared plugin settings

Alpha Vantage defaults to 24 requests per rolling day. Finnhub defaults to 50 requests per rolling minute, below its published free limit of 60. Both ledgers are shared and persist across Stream Deck restarts.

Finnhub keys stream visible prices over one shared WebSocket. This interval refreshes the REST reference quote used for previous-close calculations and is clamped to at least one hour for Finnhub.

Price is emphasized automatically. Long symbols and values shrink to fit without clipping.
